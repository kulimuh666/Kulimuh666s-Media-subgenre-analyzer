Kulimuh666's Media Subgenre Analyzer V.0024

Schreibt Subgenres und das Erscheinungsjahr in Audio-Dateien. Die Dateien bleiben auf dem PC, auf dem der Tool-Server läuft. Hermes liefert nur die Einschätzung.

Zwei Adressen, zwei Aufgaben

FeldWas es istTypisch
Tool-ServerDieses Programm. Liest Tags, schreibt Komponist und Jahr, spielt Dateien ab. Sieht nur Laufwerke auf dem PC, auf dem es läuft.http://localhost:8765
Hermes APIDas LLM. Sucht und bewertet den Track. Darf auf einem anderen PC stehen.http://127.0.0.1:8642/v1/chat/completions
Hermes API KeyBearer-Token des API-Servers. Steht in der Hermes-.env als API_SERVER_KEY.

Der Ziel-Ordner funktioniert nur, wenn der Tool-Server auf dem PC läuft, der dieses Laufwerk hat. Die Hermes-Adresse zeigt auf den PC, auf dem Hermes läuft.

Workflow

  1. Auf dem PC mit der Musik start_gui.bat doppelklicken. Das startet den Server auf localhost:8765 und öffnet diese Seite.
  2. Hermes API, Key, Worker, Timeout und Analyseart stehen unter Einstellungen. Ziel-Ordner ist ein Pfad auf diesem PC und bleibt auf der Hauptseite.
  3. Limit setzen, Aktualisieren. Fertige ausblenden lässt Dateien weg, deren Genre-Tag schon Daten hat. Neue Daten laden holt die nächsten Tracks, bei denen Genre und Komponist leer sind.
  4. Local und API stehen in der Zeile. Sie starten auch, wenn Subgenres schon da sind. Local startet die lokale LLM, falls sie noch nicht läuft, und fragt sie ohne Websuche. API ruft Hermes. Sind die Worker aus den Einstellungen schon belegt, kommt die Meldung mit den laufenden Tracks.
  5. In den Einstellungen wählst du EffNet, MAEST oder beide. Beide heißt: die Stile werden nach Score zusammengelegt, ohne eine zweite LLM. MagnaTagATune schreibt Gitarre, Rock, Metal, Stimme und Drums ins Mediafile, nach User 1 oder Album Artist. VirtualDJ muss dafür nicht laufen. Genre, Subgenres und diese Spalte haben einen Stift und schreiben direkt in die Datei.
  6. Analyseart Audio hört die ganze Datei, nicht nur drei Ausschnitte, und schreibt die erkannten Discogs-Stile in die Subgenres-Spalte und ins Komponist-Feld. Techno, Hard Techno, Minimal Techno, Schranz, Industrial, Psytrance, Goa Trance, Tech Trance, Progressive Trance und weitere, wenn das Modell sie hört. Das Genre-Feld bleibt unangetastet. Den passenden Text übernimmst du mit dem Genre-Button. Websuche und Direkt bleiben die anderen Analysearten.
  7. ▶ spielt ab und wird zu ⏸. Ordner öffnet den Explorer. Der Stift neben dem Genre öffnet ein Fenster mit dem ganzen Genre-Text und schreibt ihn direkt in die Datei. Genre übernimmt die Subgenres ins Genre-Feld.

Formate

Unterstützt: mp3, flac, m4a, mp4, aac, ogg, opus. m4a und mp4, auch eine mp4 mit Bildspur, werden als MP4 gelesen und geschrieben. Andere Endungen, oder eine Datei die sich nicht öffnen lässt, erscheinen als Format und werden nicht analysiert.

Versionen

Die Nummer steht in der Überschrift. Was sich geändert hat, steht auf der Versionsseite. Neue Funktionen gehören in diese Hilfe, nicht nur in die Versionsliste.

Doku: Installation

Hermes API-Server starten

In %USERPROFILE%\.hermes\.env (oder %LOCALAPPDATA%\hermes\.env, je nach Installation):

API_SERVER_ENABLED=true
API_SERVER_KEY=ein-langer-eigener-schluessel
API_SERVER_HOST=0.0.0.0
API_SERVER_PORT=8642

127.0.0.1 ist der Standard und nur von diesem PC erreichbar. 0.0.0.0 braucht es, wenn der Tool-Server auf einem anderen PC steht. Den Key als Hermes API Key in die App eintragen.

Starten, in cmd oder PowerShell:

hermes gateway

Erreichbar ist er dann unter http://<ip-dieses-pcs>:8642/v1/chat/completions. Prüfen:

curl http://127.0.0.1:8642/health

Kulimuh666's Media Subgenre Analyzer V.0024

Writes subgenres and the release year into audio files. The files stay on the PC that runs the tool server. Hermes only returns the judgement.

Language

The flags at the top right switch German and English. The choice is shared with the app and kept. German is the default.

Workflow

  1. On the music PC, double-click start_gui.bat.
  2. Enter the Hermes API, key, workers, timeout and analysis mode under Settings. The target folder stays on the main page.
  3. Set a limit and refresh. Hide finished drops files whose genre tag already has data. Load new data fetches the next tracks with empty genre and composer.
  4. Start keeps genre, composer and year already shown. Web search lets Hermes look the track up. Direct analyses from tags, filename and folder only, without web search, for a small or slow model. The timeout in Settings limits how long a reply may take. 0 waits with no limit.
  5. ▶ plays and turns into ⏸. The pencil next to Genre opens a window with the full genre text and writes it to the file. Genre copies the subgenres into that field.

Formats

Supported: mp3, flac, m4a, mp4, aac, ogg, opus. m4a and mp4, including a video track, are read and written as MP4.

Hermes

Install: hermes-agent.nousresearch.com. API server needs API_SERVER_HOST=0.0.0.0 and API_SERVER_PORT=8642 when the tool server runs on another PC. Start with hermes gateway.
